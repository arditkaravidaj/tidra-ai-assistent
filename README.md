# Tidra

AI assistant island for your browser — this repo holds both the browser extension and the marketing website.

| Folder | What it is |
| --- | --- |
| [`extension/`](extension/) | The Tidra browser extension (WXT + React). See its [README](extension/README.md) for setup, dev, and architecture. |
| [`website/`](website/) | The Tidra website (in development). Promo videos live here for now. |

## Quick start (extension)

```bash
cd extension
npm install
npm run dev
```
